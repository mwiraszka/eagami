Design tokens

The CSS custom properties that drive every component in the library: colors, typography, spacing, elevation, shape, and motion. Reference these tokens in your own styles via var(--token-name) to stay aligned with the system.

Theming

Every token is a CSS custom property on :root . Override at the root to retheme the entire library: 

:root {
  --color-primary-600: #2563eb;
  --font-family-sans: 'Inter', sans-serif;
  --radius-md: 0.5rem;
}

Or scope overrides to individual components where useful: 

.my-card {
  --ea-card-shadow: 0 8px 32px rgba(0, 0, 0, 0.12);
  --ea-button-font-weight: 600;
}
