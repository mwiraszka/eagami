Eagami UI

@eagami/ui is a lightweight, accessible Angular component library: 34 standalone components and 100 icons, themed entirely through CSS custom properties, and tree-shakeable so the bundle stays small.

Design principles

  • Signal-based. Inputs, outputs, and component state are signals: the idiomatic shape of a modern Angular app.
  • Themed via tokens. Use the defaults out of the box, or override any CSS custom property to fully customise the look.
  • Accessible by default. Keyboard navigation, focus management, ARIA roles, and reduced-motion support are wired in up-front.
  • No vendor lock-in. Every component is plain Angular and CSS, so the source can be read, copied, or modified like any other code in your project.
