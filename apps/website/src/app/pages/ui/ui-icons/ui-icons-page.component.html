Icons

The icon set bundled with @eagami/ui is composed of standalone Angular components that inherit their color and scale with font-size , so consumers can render at any size. The set is derived from Feather Icons by Cole Bemis (MIT License). Click an icon to copy its selector.

Brand icons

The Facebook, GitHub, Google, Microsoft, and X (Twitter) icons depict third-party trademarks and are provided only for nominative use , i.e. identifying the brand they represent in a UI (a "Sign in with Google" button, a "Share to Facebook" link, etc.). They are not licensed for general decorative use. Consumers are responsible for following each brand's guidelines:

  • Facebook: Brand resources
  • GitHub: Logos and usage
  • Google: Sign-in branding guidelines
  • Microsoft: Trademark and brand guidelines
  • X (Twitter): Brand toolkit
