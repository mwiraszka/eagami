# eagami-website

Source code for [eagami.com](https://eagami.com), the marketing site for the eagami brand and the live documentation surface for eagami UI (the [`@eagami/ui`](../../packages/ui/) component library).

Lives in the [eagami monorepo](../../) under `apps/website/`. See the [root README](../../README.md) for setup and [`CLAUDE.md`](../../CLAUDE.md) for branching, release, and deploy conventions.
